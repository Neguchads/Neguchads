## Distribution checklist

- Include the full applicable license and copyright notices in source and substantial copies, including downloadable HTML and release bundles. Do not rely solely on a README link or Git history.
- For Apache-2.0, retain the applicable NOTICE text and mark modified inherited files prominently.
- Inventory dependencies and assets at the exact published revision; review their licenses separately. Preserve notices in generated artifacts even when minifying.
- Separate code reuse from conceptual inspiration. Do not claim permission from an unlicensed public repository.
- Game software, ROMs, artwork, music and trademarks are separate rights; consult the specific project before distributing any such material.
